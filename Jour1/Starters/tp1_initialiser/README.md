# TP 1 — Initialiser un projet avec Codex

Vous partez d'un dossier **presque vide** : seul le cahier des charges `specs/cahier_des_charges.md` est fourni.
Votre mission : faire générer le projet complet par Codex, en gardant la maîtrise (plan, relecture, tests).

## Mise en route
```bash
git init
python -m venv .venv
# Windows PowerShell : .venv\Scripts\Activate.ps1      macOS/Linux : source .venv/bin/activate
python -m pip install pytest
codex
```
Suivez ensuite les consignes du guide participant (TP 1).

> Si vous êtes bloqué, le dossier `../base_facturation/` contient une version de référence : vous pourrez repartir de là.
