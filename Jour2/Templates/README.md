# Templates — à partager avec votre équipe

Ces trois documents sont conçus pour être diffusés **tels quels** après la formation, à toute l'équipe qui va
utiliser Codex sur vos dépôts (pas seulement les participants du TP). Ils reprennent et prolongent ce qui est
vu pendant les TP, sans dépendre du reste du kit.

| Fichier | Contenu |
|---|---|
| `01_Bonnes_pratiques_Codex_en_equipe.md` | Principes de base, checklist avant/pendant une tâche, agents et orchestration, sécurité, revue de code, limites à connaître. |
| `02_Templates_de_prompts_reutilisables.md` | Neuf squelettes de prompts prêts à copier-coller (feature, bug, refactor, revue, tests, documentation, exploration, orchestration en parallèle, plan). |
| `03_Conventions_equipe_Codex.md` | Où ranger quoi (partagé vs personnel), permissions par défaut, gestion des secrets, processus de revue, cycle de vie des agents/skills/hooks partagés. |

## Comment les utiliser

1. Relisez les trois fichiers et remplissez les cases « À faire avant de partager ce document » de
   `03_Conventions_equipe_Codex.md` avec les choix réels de votre équipe.
2. Versionnez-les dans vos dépôts (par exemple à la racine, ou dans un dossier `docs/codex/`), pour qu'ils
   évoluent avec le code plutôt que de rester figés dans une présentation de formation.
3. Ajoutez vos propres templates de prompts au fichier 2 au fil de l'eau, dès qu'une demande revient souvent.

Les éléments marqués **[Codex]** dans ces documents décrivent un mécanisme documenté officiellement par OpenAI ;
le reste correspond à des recommandations de méthode à adapter à votre contexte.
