Proposez un plan de tests pour le code que je nomme dans mon message. N'écrivez pas encore de code de test et ne modifiez pas le source.

Donnez un tableau : comportement | nom du test | le changement d'une seule ligne dans le source que ce test doit détecter.
Privilégiez les vérifications analytiques. Couvrez les cas limites (entrée vide, NaN, un seul échantillon) et les chemins d'erreur. Données aléatoires avec graine fixée uniquement. Aucun test ne doit recalculer sa valeur attendue avec le code testé.
Attendez mon approbation avant toute autre chose.
